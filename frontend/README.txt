NeonWave frontend starter
========================

Files:
- index.html
- css/style.css
- js/app.js

Preview:
Open index.html in Firefox or Chromium.

Notes:
- This is the frontend UI scaffold. It includes demo navigation, a cover-flow screen,
  like-button visual state, and demo playlist naming.
- Actual audio playback, file importing, persistent playlists, metadata and database
  operations are not connected yet. Those will be implemented in the Python backend.
- Google Fonts are loaded from the web; system sans-serif fallbacks are provided.
